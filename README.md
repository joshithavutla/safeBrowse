# SafeBrowse - Safe Browsing & Smart Search Guide

## About the Project

SafeBrowse is an educational website developed as part of the Digital Literacy course.

The project helps students learn safe browsing habits, smart searching techniques, phishing awareness, and online privacy.

## Objectives

- Promote safe internet browsing habits
- Explain common online threats
- Improve online search skills
- Create awareness about phishing
- Encourage protection of personal information

## Features

- Safe Browsing Guide
- Smart Search Techniques
- Phishing Awareness
- Privacy and Personal Data Tips
- Interactive Quiz with Score
- Responsive Website Design

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## Project Structure

- `index.html` - Main webpage
- `style.css` - Website styling
- `script.js` - Interactive quiz functionality

## How to Run

1. Open the live website in a web browser.
2. Navigate through the different sections.
3. Try the interactive quiz.
4. The website can also be downloaded from this GitHub repository and opened using `index.html`.
